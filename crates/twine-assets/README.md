# twine-assets

Built-in fonts of the Twine GUI library as `static` `twine_text::Font`s, one cargo feature per
font (`default = ["montserrat-14"]`) plus bundles (`fonts-latin-small`, …, `fonts-all`: every
font). Fonts that are not enabled cost nothing.

| Font | Features | Content |
|------|----------|---------|
| Montserrat Medium 8–48 px (even sizes) | `montserrat-8` … `montserrat-48` | ASCII, `°`, `•`, symbols |
| Montserrat Medium 14 px, RGB subpixel | `montserrat-14-subpx` | same |
| Montserrat Medium 16 px, Latin extension | `montserrat-16-latin-ext` | Latin-1 supplement, Latin Extended-A, `–—‘’‚“”„…€` (no ASCII: a fallback of `montserrat-16`) |
| unscii 8 / 16 px (1 bpp) | `unscii-8`, `unscii-16` | ASCII |
| DejaVu Sans 16 px | `dejavu-16-persian-hebrew` | ASCII, Hebrew, Arabic, Persian, Arabic presentation forms, symbols |
| Source Han Sans SC 14 / 16 px | `source-han-sans-sc-14-cjk`, `source-han-sans-sc-16-cjk` | ASCII, CJK punctuation, kana, full-width forms, ~1 300 common CJK characters, symbols |

The Rust sources in `src/fonts/` are generated by `cargo xtask fonts` from
`assets/fonts/fonts.toml`; the font files, their download URLs, SHA-256 hashes and licenses
are in `assets/fonts/`. They are grid-fitted with full hinting (one-pixel stems, whole-pixel
advances) and carry the default text gamma (γ 1.2 dark-on-light, 1.8 light-on-dark), so small
text stays crisp on low-DPI panels. Applications generate other fonts (sizes, scripts, a subset of
characters) with the same generator: `twine_build::font::Font` in `build.rs`,
`twine::include_font!`, or the `twine font` command.

## Bundles

Sets of fonts for applications that do not want to list sizes one by one (the individual
features stay for precise flash budgets; bundles only add fonts and combine freely):

| bundle | fonts | flash bytes |
|---|---|---:|
| `fonts-latin-small` | Montserrat 12, 14, 16 | ~58 K |
| `fonts-latin-medium` | `fonts-latin-small` + Montserrat 18, 20, 22, 24 | ~147 K |
| `fonts-latin-all` | every Montserrat size, `montserrat-14-subpx`, `montserrat-16-latin-ext` | ~666 K |
| `fonts-mono` | unscii 8, 16 | ~4 K |
| `fonts-rtl` | `dejavu-16-persian-hebrew` | ~38 K |
| `fonts-cjk` | Source Han Sans SC 14, 16 | ~289 K |
| `fonts-all` | every built-in font | ~1 M |
