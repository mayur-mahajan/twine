# Test animations

All files in this directory are original works written for Twine's test suite (generated by a
small script from hand-chosen shapes, colors and keyframes) and are licensed like the rest of
the repository (MIT OR Apache-2.0). No third-party animations are included.

| File | Content |
|------|---------|
| `loader.json` | Rotating arc drawn with animated trim paths over a faint track (demo sample) |
| `check.json` | Disc popping in (eased scale), check mark drawn by trim paths (demo sample) |
| `heart.json` | Beating heart with a linear gradient, six orbiting dots from a repeater (demo sample) |
| `masked.json` | Gradient stripes (repeater) behind an animated mask and a rotating star alpha matte (demo sample) |
| `shapes.json` | Rectangles, rounded rectangle, ellipse, star path, strokes, solid background layer |
| `nested.json` | Nested group transforms; an outer fill applied to inner geometry |
| `dash.json` | Dashed strokes with butt and square caps and a dash offset |
| `parenting.json` | Null parent → child → grandchild transform chain |
| `opacity.json` | Two overlapping shapes in one 50 % layer under an opaque layer |
| `evenodd.json` | Even-odd and non-zero fills of the same nested squares |
| `trim.json` | Circle stroke trimmed to 0–50 % |
| `repeater.json` | Three repeated rectangles with fading opacity |
| `mask_add.json`, `mask_subtract.json`, `mask_inverted.json` | Layer masks (add, add + subtract, inverted at 60 %) |
| `matte.json` | Alpha and inverted-alpha track mattes |
| `precomp.json` | Precomposition with animated time remapping |
| `legacy.json` | Old keyframe format (end values `e`, spatial tangents, trailing time-only keyframe) |
| `unsupported.json` | Luma mattes, an effect, a text layer and a rounded-corners modifier (ignored with warnings) |
